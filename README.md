# Justice Faite Portal 2.0

Официальный публичный информационный портал сообщества Justice Faite.

## Что изменилось

Это крупный релиз, а не косметическое обновление.

- Полностью новый дизайн (Liquid Glass, премиальный минимализм, тёмная палитра, изумрудные акценты)
- Уникальные баннеры для каждого раздела
- Глобальный поиск по всему контенту
- Центр обновлений с архивом релизов
- Календарь игр (структура готова; исходное расписание в архиве отсутствовало)
- Полное удаление регистрации, аккаунтов, комментариев и панели владельца
- Плоская файловая структура: все основные файлы в корне
- Контент редактируется через JSON-файлы в GitHub

## Структура

```
server.js          — минимальный Node-сервер (статика + JSON + SPA-маршруты)
index.html
style.css
app.js
config.json        — публичные настройки
content.json       — тексты всех разделов
updates.json       — релизы
schedule.json      — расписание креаторов
package.json
render.yaml
banner_*.jpg       — баннеры разделов
README.md
CHANGELOG.md
```

## Локальный запуск

Требуется Node.js 18+.

```bash
node server.js
```

Откройте http://localhost:3000

## Развёртывание на Render

1. Подключите репозиторий GitHub к существующему сервису `justice-faite-site` (или создайте новый Web Service).
2. Runtime: Node.
3. Build Command: оставьте пустым или `echo ok`.
4. Start Command: `node server.js`
5. Health Check Path: `/healthz`
6. После push в main Render выполнит автодеплой.

Домен можно оставить прежним. Persistent disk больше не нужен — база данных удалена.

## Как обновлять контент

1. Откройте репозиторий на GitHub.
2. Найдите нужный файл в корне (`content.json`, `updates.json`, `schedule.json`, `config.json`).
3. Нажмите Edit (карандаш).
4. Внесите изменения, сохраните через Commit.
5. Дождитесь автодеплоя Render (обычно 1–3 минуты).
6. Проверьте сайт.

### Тексты разделов

Редактируйте `content.json`. Каждый объект страницы содержит `slug`, `title`, `description`, `content` (Markdown-подобный текст).

### Новый релиз

Добавьте объект в массив `releases` файла `updates.json`.

### Расписание

Заполните `schedule.json`. Пример структуры:

```json
{
  "timezone": "Europe/Moscow",
  "weeks": [
    {
      "id": "2026-w48",
      "label": "24–30 ноября",
      "days": [
        {
          "name": "Пн",
          "date": "2026-11-24",
          "isToday": false,
          "events": [
            { "title": "Название игры", "time": "20:00", "host": "Креатор", "description": "" }
          ]
        }
      ]
    }
  ]
}
```

### Ссылки и настройки

Редактируйте `config.json` (`info_channel`, `join_url`, `hero_*` и т.д.).

## Удалённые функции

- Регистрация и вход участников
- Аккаунты и сессии
- Комментарии
- Панель владельца (`/admin`, `/setup`)
- SQLite и все связанные API
- CSRF, rate- для auth

## Сохранённые разделы

- Правила сообщества (`/rules`)
- Чистка (`/purge`)
- Недельная норма (`/norm`)
- Рест (`/rest`)
- Игры и активности (`/games`)
- Правила игр (`/game-rules`)
- Гайд по боту (`/guide`)
- Жетоны (`/tokens`)
- Анонимные обращения (`/anonymous`)

Оригинальные тексты восстановлены из seed-данных `server.js` исходного проекта без сокращений смысла. Страница «Игры и активности» в оригинале содержала заглушку — она сохранена как есть.

## Расписание

В предоставленном архиве `Justice_faite-main` файл расписания креаторов отсутствовал. Структура `schedule.json` подготовлена. После появления исходных данных их можно перенести без изменения кода.
