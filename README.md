# Justice Faite Portal 0.2.0

Портал сообщества Justice Faite. Это уже не статический набор HTML-файлов: приложение включает сервер, базу SQLite, регистрацию участников, авторизацию владельца, модерацию комментариев, редактор материалов и резервные копии.

## Что внутри

- Главная Liquid Glass с карточками разделов, плавающими стеклянными объектами и адаптацией под телефон.
- Отдельные страницы `/rules`, `/purge`, `/norm`, `/rest`, `/games`, `/game-rules`, `/guide`, `/tokens`, `/anonymous`.
- Каждая текстовая публикация разбита на отдельные полупрозрачные абзацы-пузыри.
- Регистрация и вход участников. Пароли хранятся в виде scrypt-хэшей, а не открытым текстом.
- Комментарии участников. Новые комментарии попадают на проверку владельцу.
- Одноразовое создание аккаунта владельца при первом запуске.
- `/admin`: редактирование текстов, заголовков, ссылок, порядка и видимости страниц; настройки главной; username и deep-link-параметры бота; количество участников; модерация комментариев; блокировка аккаунтов.
- Гайд бота заполнен по текущему коду `Larkins2007/anonymous-flood-bot`: самостоятельный рест, экономика и анонимная связь.
- Резервные копии SQLite: ежедневные автоматически (до 14), ручные из панели (до 20), с возможностью скачать файл.
- Защищённый endpoint для будущей синхронизации числа участников от Telegram-бота.

## Локальный запуск

Требуется Node.js 22.5 или новее. Внешние npm-пакеты не нужны: сервер использует встроенный HTTP-модуль и `node:sqlite`.

```bash
cp .env.example .env
node server.js
```

Открой `http://localhost:3000/setup`. При первом запуске сервер напечатает в терминале одноразовый `OWNER_SETUP_KEY`. Введи его в форму первичной настройки, создай логин, отображаемое имя и пароль владельца. После этого ключ больше не нужен, а повторно создать владельца через эту форму нельзя.

Для локального запуска папка `data/` создаётся автоматически. Не удаляй `data/justice-faite.sqlite`, если хочешь сохранить аккаунты, комментарии и изменения сайта.

## Развёртывание на Render

В проект добавлен `render.yaml`. Он описывает отдельный Web Service и постоянный диск, подключённый к `/var/data`. Вся база и резервные копии хранятся именно там.

Важно: Render Free не поддерживает persistent disks. Для этой схемы нужен платный Web Service с постоянным диском. В Blueprint указан compute plan `0.5c-512mb` (текущий эквивалент Starter) и диск 1 GB. По текущему прайсу Render это ориентировочно $7/мес за Web Service плюс $0.25/мес за 1 GB SSD, до налогов и дополнительных расходов. Без постоянного диска база SQLite, регистрации, комментарии и изменения владельца могут исчезнуть при перезапуске или новом деплое. Сервис с диском работает в одном экземпляре и не масштабируется горизонтально; при деплое возможна короткая пауза.

Шаги:

1. Загрузи папку проекта в отдельный GitHub-репозиторий.
2. В Render выбери создание Blueprint и подключи этот репозиторий.
3. Проверь, что Render создаёт сервис `justice-faite-site`, диск `justice-faite-data` и переменные `OWNER_SETUP_KEY`, `BOT_SYNC_TOKEN`.
4. После первого успешного деплоя открой `https://<адрес-сайта>/setup`.
5. Найди одноразовый `OWNER_SETUP_KEY` в логах сервиса, затем создай аккаунт владельца. После регистрации владелец управляет содержимым сайта через `/admin`.

Не публикуй `.env`, ключи или содержимое папки `data/` в GitHub. Они исключены через `.gitignore`.

## Счётчик участников

В `/admin` число участников можно менять вручную. Позже бот сможет обновлять его через endpoint:

`POST /api/bot/stats`

Заголовок:

`Authorization: Bearer <BOT_SYNC_TOKEN>`

Тело JSON:

```json
{"memberCount": 123}
```

`BOT_SYNC_TOKEN` хранится только в переменных окружения сервера и в конфигурации самого бота. Никогда не вставляй его в HTML или браузерный JavaScript.

## Telegram-кнопки в гайде

В `/admin` укажи username бота без `@` и параметры запуска для REST, жетонов и анонимных сообщений. После этого карточки сформируют ссылки вида:

`https://t.me/<bot_username>?start=rest`

Telegram открывает личную переписку и передаёт боту `/start rest`. Чтобы бот сразу показывал нужную форму или запускал нужную функцию, его обработчик `/start` должен распознавать параметры `rest`, `tokens` и `anonymous`. См. `bot-integration/README.md`.

## Резервные копии и восстановление

Панель владельца позволяет создавать и скачивать копии. Сервис также формирует ежедневную копию в `data/backups/`.

Для восстановления:

1. Останови приложение.
2. Сохрани текущий файл базы отдельно.
3. Замени `data/justice-faite.sqlite` нужной скачанной копией.
4. Удали рядом с базой файлы `justice-faite.sqlite-wal` и `justice-faite.sqlite-shm`, если они остались после остановки.
5. Запусти приложение и проверь страницы, аккаунты и комментарии.

Не восстанавливай базу заменой файла, пока приложение работает.

## Важные недостающие сведения

Содержимое общей страницы RULES перенесено из исходной публикации. Тексты PURGE, NORMA, REST и GAME RULES внесены из материалов, присланных в чате. Раздел GAMES оставлен как отдельная страница со ссылкой на оригинал, потому что полный текст этой публикации пока не был предоставлен.

Telegram deep-link-кнопки подготовлены. Для них нужен небольшой дополнительный разбор параметров `rest`, `tokens` и `anonymous` в существующем обработчике `/start` бота. Инструкция и готовый фрагмент находятся в `bot-integration/README.md`. В текущем коде самостоятельный рест оформляется в основном чате; экономика также работает в группе. Анонимная связь начинается в личной переписке, но администрация видит имя, username и Telegram ID отправителя.
