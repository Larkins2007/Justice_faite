# Changelog

## 2.0.0 — 2026-11-25

### DESIGN
- Новая визуальная система: Liquid Glass, премиальный минимализм, тёмная палитра, изумрудные/мятные акценты
- Уникальные тематические баннеры для всех 9 разделов
- Горизонтальная галерея разделов с поддержкой свайпа
- Переработанная главная страница (hero, поиск, галерея, обновления, расписание, информация)
- Улучшенная типографика (Manrope + Space Grotesk)

### FEATURES
- Глобальный поиск с подсветкой, фильтрами и мгновенными результатами
- Центр обновлений с подробными релизами и категориями
- Недельный календарь креаторов (структура готова)
- Отдельные URL для каждого раздела
- Удобная мобильная навигация

### CONTENT
- Все оригинальные тексты разделов сохранены
- Контент вынесен в content.json, updates.json, schedule.json, config.json
- Редактирование через GitHub без панели владельца

### SECURITY
- Полное удаление регистрации, аккаунтов, сессий, CSRF
- Полное удаление комментариев и связанного API
- Полное удаление панели владельца и административных маршрутов
- Удаление SQLite и persistent disk requirement
- Минимальный безопасный статический сервер

### PERFORMANCE
- Плоская файловая структура (без public/, pages/, components/)
- Нет внешних npm-зависимостей
- Лёгкий клиентский JS без фреймворков
- Оптимизация под мобильные устройства

### Известные ограничения
- Исходное расписание игр для креаторов в архиве отсутствовало — schedule.json содержит пустую структуру
- Страница «Игры и активности» в оригинале имела заглушку — сохранена без выдумывания контента
- Баннер для раздела «Анонимные обращения» временно использует вариант от «Рест» (лимит генерации изображений)
